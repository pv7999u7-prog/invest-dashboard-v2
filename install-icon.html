安裝「投資總覽 v2」主畫面圖示

用描述檔把圖示直接裝到主畫面，不靠 Safari 抓圖

  1. 按上面的按鈕，跳出提示時按「允許」或「下載」
  2. 打開 設定 App，最上面會出現「已下載描述檔」，點進去
    （沒看到的話：設定 → 一般 → VPN 與裝置管理）
  3. 按右上角「安裝」→ 輸入 iPhone 密碼 → 再按「安裝」→「完成」
  4. 回主畫面就會看到 HK 圖示的「投資總覽 v2」

如果按了按鈕只下載成檔案：打開「檔案」App → 下載項目 → 點「投資總覽v2圖示.mobileconfig」，再做第 2 步。
描述檔只包含 App 網址與圖示。要移除：設定 → 一般 → VPN 與裝置管理 → 投資總覽 v2 主畫面圖示 → 移除描述檔。
