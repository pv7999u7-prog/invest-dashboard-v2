# 投資總覽 v2（雙向輸入）

iPhone／iPad 用的投資總覽 App（PWA）。打開時會透過 Google Apps Script 讀取私人試算表「Investment Auto v2」的最新數據；也可以直接在 App 裡輸入資料，寫回試算表。試算表那邊改的東西，App 下拉更新就看得到。

- 網址：https://pv7999u7-prog.github.io/invest-dashboard-v2/
- 這個 repo 只有程式碼，**沒有任何財務資料**。資料只會在輸入密碼後，從試算表直接傳到你的裝置上。
- 舊版（只讀）在 https://pv7999u7-prog.github.io/invest-dashboard/ ，兩個 App 的設定和資料互不影響。

## 第一次設定

1. 打開試算表「Investment Auto v2」→ **擴充功能 → Apps Script**
2. 把 [`apps-script/Code.gs`](apps-script/Code.gs) 整段貼上（取代原本的內容），把 `KEY` 改成你自己的密碼，存檔
3. **部署 → 新增部署作業 → 類型選「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 第一次部署會要求授權（讀寫試算表、設定定時執行），按允許
4. 複製部署後的網址（`https://script.google.com/macros/s/…/exec`）
5. 在 iPhone Safari 打開上面的 App 網址 → 分享 → **加入主畫面**
6. 從主畫面打開 App，填入網址和密碼

## App 裡可以輸入的資料

| 位置 | 輸入 | 寫到試算表哪裡 |
|---|---|---|
| 總覽 → ＋ 成本變更 | 投入／撤出的總金額，以及分到台股、CUBE、Firstrade、加密貨幣各多少（都填台幣，美股與加密貨幣依匯率換成美金寫入） | Total Overall 歷史表；台股、美股交易表的出入金；各帳戶閒置現金 |
| 台股／美股 → ＋ 買賣 | 股號或股名、單價、股數、買或賣 | 交易表加一列；閒置現金加減；買進時更新均價（移動平均）；新股票自動加進持股清單與 Price 分頁 |
| 加密貨幣 → ＋ 買賣 | 幣名、存於、單價（USD）、顆數 | 幣分頁顆數加減，用 Binance 的 USDT 付款／收款；新的幣自動加進持有清單；Y～AF 欄留交易紀錄 |
| 加密貨幣 → ＋ 出入金 | 轉入／轉出、來源（台幣、台股、CUBE、Firstrade）、USDT 數量、台幣金額 | 台幣＝新資金，記在 Total Overall；台股／美股＝內部轉帳，對方閒置現金加減並記在該交易表 |
| 小孩帳戶／我的定期定額 → ＋ 本月定期定額 | 本月總投入（台幣）、各檔本月投入與目前累計股數 | Total Overall 歷史表（不用再到總覽記成本變更）；各定期定額表的總投入、累計股數 |
| 長期計畫 → 編輯 | 年化報酬率、每年投入、各年度計畫與實際投入 | Plan 分頁 |
| 固定支出 → 點月份 | 該月項目與金額（清空名稱＝刪除） | 固定支出分頁；年度分類依名稱自動加總 |
| 房產 → 調整估價 | 估計單價（萬/坪）、車位估價（萬） | House 分頁 L、K 欄 |
| 房產 → 房貸卡片的編輯 | 利率、每月還款（空白會依利率自動估算）、到期日 | House 分頁房貸列 |
| 里程碑 → ＋ 新增／點項目 | 日期與內容；可修改或刪除 | Milestone 分頁 |
| 職涯與薪資 | 年前分紅（職務加給＋年終）、年中分紅、新年度／調薪／升遷、改職稱 | BB 分頁 |

每次從 App 寫入，都會在試算表的「App 紀錄」分頁留一筆。

## 修改、刪除與復原

- **更多 → 明細與復原**：資金異動、台股、美股、加密貨幣的每一筆都可以點進去修改或刪除；閒置現金、均價、加密貨幣顆數會跟著調整。總覽和台股、美股頁的「最近」清單也可以直接點。
- **復原上一步**：每次從 App 寫入（新增、修改、刪除都算），改到的格子會先記在隱藏的「App 復原」分頁，最近 30 步都可以一步步倒回去。寫入成功的提示上也有「復原」按鈕。
- 寫到一半失敗時，會自動把已經改的部分還原，不會留下半套資料。
- **閒置現金**：總覽列出各帳戶（台股 CUBE、美股 CUBE／Firstrade、小孩美股帳戶、加密貨幣 USDT）的閒置現金，台股、美股、加密貨幣、小孩帳戶頁也有各自的；點一下可以直接改成券商上的數字（例如收到股利），只改現金、不算投入成本，也能復原。定期定額帳戶沒有閒置現金。
- 復原是照順序倒回最後一步；如果中間直接在試算表上改過同一個地方，復原前先確認一下。

## 自動紀錄

Apps Script 每天晚上 10 點執行一次（第一次從 App 連線時自動設定）：

- **每週三**：在 Total Overall 歷史表加一列，記下當天總資產（資金異動空白），資產走勢圖因此每週都有點。
- **每年 12/31**：Plan 分頁填當年「實際資產年底總結」與「年度實際投入」（萬），Total Overall 的年底總結表填當天快照。
